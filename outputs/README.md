# Output Folder Layout

Each experiment folder is organized the same way:

```text
outputs/
|-- exp1_data_scaling/
|   |-- old_results/   # historical/original recorded results
|   |-- new_results/   # corrected rerun summaries and report figures
|   `-- raw_runs/      # per-job outputs, logs, predictions, training artifacts
`-- exp2_gridsearch/
    |-- old_results/
    |-- new_results/
    `-- raw_runs/
```

Use `new_results/` for current-script summaries and report figures. Keep
`old_results/` for comparison with the historical records. Do not cite
`raw_runs/` directly in the report; it is for traceability and debugging.

The original historical files that were previously grouped under
`outputs/outputs_out/` have been moved directly into each experiment's
`old_results/` folder.

## Experiment 1: Data Scaling

```text
outputs/exp1_data_scaling/
|-- old_results/
|   |-- results.json
|   `-- data_scaling_analysis.png
|-- new_results/
|   |-- results.json
|   |-- results.csv
|   |-- summary.csv
|   |-- best_model.json
|   `-- figures/
|       `-- data_scaling_analysis.png
`-- raw_runs/
    |-- job_logs/
    |-- size_100/
    |-- size_500/
    |-- ...
    `-- experiment.log
```

The new figure is generated by:

```bash
python analysis/01_data_scaling_analysis.py
```

To regenerate both versions explicitly:

```bash
python analysis/01_data_scaling_analysis.py --results-file outputs/exp1_data_scaling/old_results/results.json --output-file outputs/exp1_data_scaling/old_results/data_scaling_analysis.png
python analysis/01_data_scaling_analysis.py --results-file outputs/exp1_data_scaling/new_results/results.json --output-file outputs/exp1_data_scaling/new_results/figures/data_scaling_analysis.png
```

## Interpretation

The current-script summaries are the main reporting artifacts because the
current code explicitly forces the target language token (`nob_Latn`) during
generation, which is appropriate for NLLB-style multilingual translation
models. The historical results are retained to make the result-checking process
transparent.
